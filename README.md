# Researchers & Publications – Jakarta EE Services

This project demonstrates Jakarta EE technologies (JPA, EJB, SOAP and REST web services) on WildFly with a PostgreSQL database.

It consists of three components:

| Component | Description |
|-----------|-------------|
| **`serverSoap`** | SOAP web service that manages information about researchers. |
| **`serverRest`** | REST web service that manages information about publications. It also provides a web front end that lists publication titles alongside researcher names. |
| **`client`** | Console application that accesses both servers. |

## Prerequisites

- JDK (version used in development: 27 – adjust if different)
- Apache Maven
- PostgreSQL (version used in development: 18)
- WildFly 38.0.0.Final (already bundled in `wildfly-38.0.0.Final/`)

## Setup

### Step 1 – Create and configure the database

1. Create an empty PostgreSQL database.
2. Replace the following placeholders with your own values:

   | Placeholder | Replace with |
   |-------------|--------------|
   | `DB_NAME`   | Your database name |
   | `DB_USER`   | Your database user |
   | `DB_PASS`   | Your database password |

3. Apply the replacements in these files:

   - `serverRest/rest-jpa/src/test/resources/META-INF/persistence.xml`
   - `serverSoap/jpa/src/test/resources/META-INF/persistence.xml`
   - `wildfly-38.0.0.Final/standalone/configuration/standalone-full.xml` (the PostgreSQL datasource definition, around lines 141 and 148)

### Step 2 – Load the sample data

Run each of the following classes **once** from your IDE to populate the database with researchers and publications:

- `serverSoap/jpa/src/test/java/WriteData.java`
- `serverRest/rest-jpa/src/test/java/WriteData.java`

> **Note:** These loaders are in the `test` folder so they are excluded from the final `.ear` files built by `mvn clean package`.


### Step 3 – Start the server

*(Optional)* Rebuild both server projects and deploy the resulting `.ear` files. Prebuilt `.ear` files are already included in WildFly's `deployments` folder.

```bash
# Windows
mvn clean package -Doutput=.\wildfly-38.0.0.Final\standalone\deployments

# macOS / Linux
mvn clean package -Doutput=./wildfly-38.0.0.Final/standalone/deployments
```

Run this command in both `serverRest/` and `serverSoap/`.

Then start WildFly from inside the `wildfly-38.0.0.Final` directory:

```bash
# Windows
run.bat

# macOS / Linux
./run.sh
```

The provided scripts start the server on port **8180** (instead of the default 8080). All components are configured for 8180, so please use these scripts rather than the standard WildFly start command.

### Step 4 – Start the client

*(Optional)* Rebuild the client. A prebuilt `client.jar` is already included.

```bash
mvn clean package
```

Run the client in a new terminal, from the `client/` directory, while the server is running:

```bash
java -jar target/client.jar
```

The following menu is displayed:

```text
1  - List all researchers
2  - Filter researchers by name
3  - Filter researchers by interest
4  - Filter citations by name

5  - List publications
6  - Filter publications by title
7  - Filter publications by researcher
8  - Filter publications by journal
9  - Filter publications by journal and researcher
10 - Filter publications by institution and period of time
11 - Exit
```

### Step 5 – Open the web front end

Once the server is running, open the following URL in a browser:

```text
http://localhost:8180/webapp/publications
```
